Web Scrapper

Amazon ASINs, Flipkart PIDs and Flipkart compatible-model lists, in the browser.

idle

Headful gets blocked far less often — leave headless off unless you know the run is going through. A Chromium window will open; don't close it mid-run.

Reads the product page text rather than Flipkart's class names, which rotate. Prices are scoped to the buy box, so a "Similar Products" price never gets mistaken for this product's.

The tool tries to open the filter overlay itself. If it can't, it says so and waits ~12s — open the overlay in the Chromium window it launched and it will carry on.
