Web Scrapper

A small toolkit for pulling product data off Indian e-commerce sites — a Playwright scraper for Amazon ASINs, and a zero-install console snippet for Flipkart's compatible-models list.

View on GitHub Quick start

What's in the box

Amazon ASIN scraper

Feed it a spreadsheet of ASINs. It opens each amazon.in/dp/<ASIN> page in a real Chromium window, parses the DOM with BeautifulSoup, and writes one row per product to Excel.

Flipkart console snippet

Paste into DevTools on an open "Compatible Mobiles" filter. It scrolls the overlay, collects every model name, and downloads a CSV. No class names, so Flipkart's CSS-hash rotation doesn't break it.

Quick start

git clone https://github.com/pethupraveen/web-scrapper.git
cd web-scrapper

python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate

pip install -r requirements.txt
playwright install chromium

Run the Amazon scraper

Drop an input_asins.xlsx beside the script with an ASIN column, then:

python Amazon_Updated_Script.py

Output goes to scraped_amazon_results.xlsx, one row per ASIN:

  • ASIN
  • Status
  • Title
  • Price
  • Rating
  • ReviewCount
  • Bullets

Run the Flipkart snippet

  1. Open a Flipkart listing and open the Compatible Mobiles filter overlay.
  2. Open DevTools (F12) → Console.
  3. Paste console_snippet.js, press Enter, and let it finish scrolling.
  4. compatible_mobiles.csv downloads automatically.

Design notes

Headful on purpose. Chromium launches with headless=False and an en-IN locale — it gets challenged far less often than a headless session.

Paced, not hammered. Two waits per product (2–4s after load, 2–5s between ASINs) keep the request rate close to human browsing.

Fails soft. A blocked or missing page returns Status = "Blocked/Not Found" and an exception returns Status = "Error: …". Either way the run continues and the row is kept, so a single bad ASIN never costs you the batch.

Price selectors are a chain. Amazon serves several price layouts; the scraper tries .priceToPay, then .a-price, then the two legacy #priceblock_* ids, and takes the first hit.

Excel inputs and outputs are gitignored — the repo holds the code, not the data. Scrape responsibly and within each site's terms of use.
